# HEALTH · Nếp

Ứng dụng theo dõi cuộc sống hằng ngày, giao diện đen trắng và tiếng Việt.

Hiện tại: bản xem trước tương tác để duyệt giao diện trước khi triển khai Next.js và kết nối Supabase / Vercel.

## Xem giao diện

```sh
node preview/server.cjs
```

Mở http://127.0.0.1:4173. Có ghi hoạt động, lọc nhật ký, ghi nước, thói quen và tổng quan tuần với dữ liệu minh họa. Thay đổi được đặt lại khi tải trang; chưa lưu vào cơ sở dữ liệu.

Xem [ghi chú bản mẫu](preview/README.md) để biết cấu trúc dự kiến theo project tham chiếu.
